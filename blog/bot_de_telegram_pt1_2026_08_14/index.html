Bot de Telegram Parte 1

PythonAPIsBot

Introducción

Por pura diversión y aburrimiento quise hacer un bot de telegram para que mi grupo de amigos se entretuvieron buscando imágenes de sus personajes favoritos Mediante distintos comandos mas la etiqueta correcta, el bot responde con una imagen aleatoria con la etiqueta que previamente especificada

Nombre de usuario por si desean probarlo:

@NopalHackBot

Y puedes descargar el bot en Github

Sin embargo, el bot comenzó a presentar problemas que se abordará más adelante Mientras veremos el funcionamiento del bot y mecanismo para enviar imagenes con características únicas

Funcionamiento

Aunque Telegram tiene la opción de desplegar los comandos disponibles desde un menú, es necesario hacer un repaso siendo más específicos así como futuros comandos

Comandos

En principio, el bot siempre devolverá una imagen aleatoria incluso si no introduces una etiqueta, pero es necesario saber el origen de la imagen para que no te topes con algo indeseado o quieras más variedad

Comandos de Gelbooru

Gelbooru es la plataforma de imágenes principal del bot habiendo de todo tipo de contenido aparte de ser el más completo y amigable comparado a su hermano mayor Danbooru

  • /glbr: devuelve una imagen aleatoria sin implementar ningun filtro del tipo de contenido que buscas
  • /glbr_s: devuelve una imagen aplicando filtro para devolver contenido apto para todo publico
    Nota: esto a veces no funciona, eso depende más de la plataforma de Gelbooru
  • /glbr_q: devuelve una imagen sugerente con conotaciones sexuales, desde este punto se recomienda discreción
  • /glbr_x: devuelve una imagen de carácter explicito normalmente contenido pornografico, se recomienda discreción devido a que puedes encontrar imágenes que pueden herir la sensibilidad
Comando de Safebooru

Safebooru es una plataforma de imagenes similar a otras plataformas de tipo “booru” donde unicamente se guardan imagenes aptas para todo publico, debido a esto es escasa la cantidad de contenido

  • /sfbr: el comando principal para devolver imagenes de esta plataforma
Otro(s?)

-/dlt: para eliminar cualquier mensaje hecho por el bot (esto devido a la naturaleza del contenido explicito de Gelbooru y en un futuro de otras plataformas)

Futuros comandos

Funciones

Debido a que hay etiquetas moralmente despreciables e incluso me cuestiono su legalidad, he e implementado funciones para advertir al usuario

Censurar imagenes

Dentro del archivo XML src\bot_opts.xml en la etiqueta <tags_censuradas> se sencuentra una lista de etiquetas bastante negativas por si el contenido sexual explicito no era suficiente

<tags_censuradas>  s
    <tag>rape</tag>
    <tag>gore</tag>
    <!--    [...]   -->
</tags_censuradas>

Debido a esto, he implementado la opción para censurar como "spoiler" la imagen enviada

#[...]
censurar = any(tag in self.tags_censuradas for tag in tags_lst)
#[...]
self.bot.send_photo(chat_id=message.chat.id, photo=file_url, caption=caption, parse_mode="HTML", has_spoiler=censurar)
#[...]

Igual el usuario tiene el comando /dlt para eliminar el contenido enviado

for tag in parametros:

Problemas

Hace unos meses despues de la salida de la primera versión del bot, el servicio principal de contenido multimedia Gelbooru comenzó a presentar problemas, enviando de manera incorrecta la información pero la API funciona de manera correcta Esto se descubrió debido a que recibe de manera correcta las URLs pero el contenido enviado no corresponde a lo esperado, la url del archivo redirigia al post en Gelbooru enviando contenido HTML en vez de contenido multimedia. La seguridad implementada comenzó a entorpecer las funciones del Bot, la unica solución es usar encabezados en las peticiones, sin embargo, la API de Telegram o mejor dicho, el propio Telegram no permite cambiar el user-agent u otras variables. la segunda solución es guarda en memoria RAM el contenido multimedia de manera tamporal, suena bien hasta que recuerdo que los recursos de Render son pocos, hice la prueba en mi PC (16GB de RAM, RTX 3050, Rysen 5) y las imagenes normales consumen bastantes Megabites aparte de que tarda bastante, cuando son videos la cosa es aun peor pasando a consumir más del doble de los recursos que tiene disponible Render.


from apis import gelbooru_api

for i in range(5):

    response = requests.get(result[0])

    if not response.headers.get('Content-Type').startswith('text/html'):
        print(result[0])

        print(f"RAM inicial: {ram_mb():.2f} MB")

        response = requests.get(
            result[0],
            timeout=30
        )

        print(f"Después de requests: {ram_mb():.2f} MB")

        image = BytesIO(response.content)

        print(f"Tamaño del archivo: {len(response.content) / 1024 / 1024:.2f} MB")

        image.close()

        del image
        del response

        print(f"Después de liberar: {ram_mb():.2f} MB")
        break
